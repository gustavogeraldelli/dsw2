# Bora

O Bora é uma aplicação que sugere ao usuário lugares e atividades para fazer no tempo livre.

A ideia é utilizar a localização do usuário para encontrar opções próximas e permitir que ele filtre os resultados de acordo com critérios como distância e preço.

## Funcionalidades planejadas
* utilizar a geolocalização do navegador para obter a posição do usuário;
* consultar uma API externa de lugares usando as coordenadas obtidas;
* mostrar uma lista de lugares e atividades próximos;
* filtrar os resultados por distância, preço e outros critérios;
* salvar lugares nos favoritos usando `localStorage`;
* permitir que o usuário salve preferências, como distância ou faixa de preço padrão, para reutilizá-las ao abrir a aplicação novamente.

## Páginas
* **Início:** lista de lugares e atividades, junto com os filtros;
* **Detalhes:** informações completas sobre um item selecionado;
* **Favoritos:** lugares salvos pelo usuário;
* **Preferências:** possível página para configurar e salvar os valores padrão dos filtros.
