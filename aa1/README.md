# Bora

Projeto da disciplina Web 2.

Gustavo Gonçalves de Souza Geraldelli, RA 800523

O Bora é uma aplicação para ajudar a encontrar lugares e atividades de acordo com categoria, preço e distância. Os lugares e as avaliações usam dados de exemplo.

## Páginas

- `index.html` - página principal com sugestões de lugares, filtros de categoria, distância e preço e opção de favoritar.
- `detalhes.html` - informações, notas e comentários do lugar selecionado.
- `favoritos.html` - lugares salvos no `localStorage`, com opção de remover favoritos.
- `mapa.html` - mapa-múndi interativo usando Leaflet e OpenStreetMap.
- `preferencias.html` - formulário visual com campos de categorias e distância.

O projeto utiliza HTML, CSS, JavaScript e Tailwind CSS. As páginas compartilham a identidade visual e possuem layout responsivo para celular, tablet e desktop.

Os cards principais e as informações dos lugares estão escritos no HTML. O JavaScript controla os filtros, a seleção dos detalhes e os favoritos, que permanecem salvos após recarregar a página.

## Como executar

Abra o arquivo `index.html` no navegador.
